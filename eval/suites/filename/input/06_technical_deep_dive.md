Spent the entire week refactoring our message queue consumer. We were using a pull-based approach with SQS but the latency was killing us. Migrated to a push-based model with SNS fan-out to multiple SQS queues. Each microservice now gets its own queue with a dead letter queue for failed messages. The throughput improvement is dramatic — we went from processing 500 messages per second to over 3000. I also added proper circuit breakers using the resilience4j library so we don't cascade failures anymore. Wrote documentation for the whole thing and did a knowledge sharing session with the team.
