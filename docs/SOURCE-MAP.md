# Source map

Start here before guessing filenames. All paths are relative to the repository root; use `rg -n 'TypeName' Sources` for embedded types. Build and verification commands live in [README](../README.md), [scripts](../scripts/README.md) and [evaluations](EVALUATIONS.md).

| Concern | Active source / boundary |
|---|---|
| App launcher, menus, debug fixtures | [AppMain.swift](../Sources/CaptainsLogApp/AppMain.swift); [DemoMode.swift](../Sources/CaptainsLogApp/DemoMode.swift) seeds presentation-only demo data. |
| Shipped Logs UI and Settings | [FieldNotesContentView.swift](../Sources/CaptainsLog/FieldNotesContentView.swift): embedded private `FieldNotesEntriesView`, `FieldNotesEntryRow`, `FieldNotesEntryDetailView`, `FieldNotesRecordDock`, `FieldNotesSettingsView`, `ThirdPartyNoticesView`, onboarding and delete dialog. These do not have individual source files. |
| Appearance | [FieldNotesTheme.swift](../Sources/CaptainsLog/FieldNotesTheme.swift), [FieldNotesToggleStyle.swift](../Sources/CaptainsLog/FieldNotesToggleStyle.swift); conceptual references in [design](../design/README.md). |
| App state / entries | [AppState.swift](../Sources/CaptainsLog/AppState.swift) includes entry/metadata types; [DirectoryWatcher.swift](../Sources/CaptainsLog/DirectoryWatcher.swift), [EntryRowBehavior.swift](../Sources/CaptainsLog/EntryRowBehavior.swift), [RecordingState.swift](../Sources/CaptainsLog/RecordingState.swift). |
| Processing queue / model lifecycle | [ProcessingCoordinator.swift](../Sources/CaptainsLog/ProcessingCoordinator.swift), [ModelManager.swift](../Sources/CaptainsLog/ModelManager.swift). |
| Pipeline / persisted stages | [Pipeline.swift](../Sources/CaptainsLogCore/Pipeline.swift) includes stage, entry, result and operation types. Read [ADR-016](0016-keep-pipeline-stage-outputs-separate.md) before changing artifacts. |
| Text inference / stage prompts | [LLM.swift](../Sources/CaptainsLogCore/LLM.swift) contains `ModelContainer` and the serial inference gate; [Cleanup.swift](../Sources/CaptainsLogCore/Cleanup.swift), [Categorize.swift](../Sources/CaptainsLogCore/Categorize.swift) (category/manifest types), [Filename.swift](../Sources/CaptainsLogCore/Filename.swift), [Enrich.swift](../Sources/CaptainsLogCore/Enrich.swift). Prompts in [prompts](../prompts/); rendering in `PromptLoader`, `PromptResolver`, `PromptXML`, `PromptDebug`. |
| Audio / transcription | [Recorder.swift](../Sources/CaptainsLogCore/Recorder.swift), [RecorderOperations.swift](../Sources/CaptainsLogCore/RecorderOperations.swift), [Transcriber.swift](../Sources/CaptainsLogCore/Transcriber.swift). |
| Configuration / model storage | [Config.swift](../Sources/CaptainsLogCore/Config.swift) contains `CaptainsLogConfig`; [ConfigManager.swift](../Sources/CaptainsLog/ConfigManager.swift) handles UI persistence/reload; [ModelStorage.swift](../Sources/CaptainsLogCore/ModelStorage.swift). See [ADR-017](0017-keep-configuration-outside-ui-state.md). |
| Search / indexing | [Search.swift](../Sources/CaptainsLogCore/Search.swift), [Embeddings.swift](../Sources/CaptainsLogCore/Embeddings.swift), [SearchManager.swift](../Sources/CaptainsLog/SearchManager.swift). |
| Updates | [AppUpdater.swift](../Sources/CaptainsLogCore/AppUpdater.swift), [UpdateManager.swift](../Sources/CaptainsLog/UpdateManager.swift). |
| CLI | [CL.swift](../Sources/cl/CL.swift) contains command types; [EvalBatch.swift](../Sources/cl/EvalBatch.swift) is the internal sequential text-suite transport. |
| Tests / evals | Framework-free tests in [run-tests/main.swift](../Sources/run-tests/main.swift), not `Tests/`; evaluator tooling checks in [test-evals.rb](../scripts/test-evals.rb). Active fixtures under `eval/{transcribe,cleanup,categorize,filename,enrich}`; [docs/tng-eval](tng-eval/README.md) is a reference corpus, not the active suite. |
| Native UI fixture seams | [DesignFixtures.swift](../Sources/CaptainsLog/DesignFixtures.swift), `CAPTAINSLOG_UI_FIXTURE`, [test-ui.sh](../scripts/test-ui.sh). Use isolated config to bypass demo seeding. |
| Legacy UI boundary | [ContentView.swift](../Sources/CaptainsLog/ContentView.swift), [FirstRunView.swift](../Sources/CaptainsLog/FirstRunView.swift), [Theme.swift](../Sources/CaptainsLog/Theme.swift), [LCARSKit.swift](../Sources/CaptainsLog/LCARSKit.swift) are the older interface, not the launcher’s current root. Public legacy views are not proven removable: check downstream SwiftPM users, previews and resources under [ADR-007](0007-framework-free-test-coverage.md#legacy-code-review). |

Before architecture changes, search the [ADRs](../README.md#architecture-decisions). Keep current work and acceptance status in [Backlog](../backlog/tasks/), and preserve dated evaluation evidence separately from open tasks.
